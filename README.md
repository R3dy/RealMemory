# realmemory

An OpenCode plugin that gives AI agents real persistent memory — a weighted, indexed database that stores what agents learn across sessions and recalls it automatically when relevant.

**Status:** In development

## Installation

```json
// opencode.json
{
  "plugin": ["realmemory"]
}
```

Or from git:
```json
{
  "plugin": ["realmemory@git+https://github.com/user/realmemory.git"]
}
```
